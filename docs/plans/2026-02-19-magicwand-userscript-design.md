# Magicwand 油猴脚本设计文档

## 概述

一个油猴脚本，支持识别网页图片并添加AI编辑功能。用户可使用预置提示词或自定义提示词编辑图片，编辑后支持滑块对比查看新老图片差异。

## 功能需求

1. 图片检测与按钮注入
2. 编辑面板（预置提示词 + 自定义输入）
3. 滑块对比新老图片
4. API调用（ComfyUI/BentoML服务）
5. 油猴菜单配置管理

## 架构设计

### 整体结构

```
┌─────────────────────────────────────────────────────┐
│                    油猴脚本                          │
├─────────────────────────────────────────────────────┤

```

### 文件结构

单个JS文件：`magicwand.user.js`

## 模块详细设计

### 1. 图片检测与按钮注入

**检测策略：**
- `MutationObserver` 监听DOM变化，检测新增`<img>`元素
- 初始加载时遍历已有图片
- 过滤条件：宽高均≥100px的可见图片
- 排除：已处理的图片（标记`data-magicwand-processed`属性）

**按钮样式：**
- 绝对定位在图片右下角
- 半透明魔法棒图标（SVG inline），hover时高亮
- z-index确保在最上层
- 点击时阻止事件冒泡

### 2. 编辑面板UI

**触发流程：**
1. 点击魔法按钮 → 显示编辑面板
2. 面板定位：图片上方或下方，避免遮挡

**面板布局：**
```
┌─────────────────────────┐
│ [人物动作] [人物穿着]    │
│ [背景替换] [自定义...]   │
├─────────────────────────┤
│ 输入框 (自定义时显示)    │
│ [发送] [取消]           │
└─────────────────────────┘
```

**交互：**
- 点击预置按钮：直接发送请求
- 点击自定义：展开输入框
- 回车/点击发送：提交请求
- 点击外部/取消：关闭面板

**状态反馈：**
- 发送中：面板显示loading
- 成功：关闭面板，进入对比模式
- 失败：显示错误信息，保留面板

### 3. 滑块对比功能

**视觉示意：**
```
┌────────────────────────┐
│ 老图 │      新图       │
│      │                 │
│      │  ← 滑块竖线     │
└────────────────────────┘
       ↑
    鼠标位置
```

**实现原理：**
1. 创建对比容器，原图和新图绝对定位叠加
2. 原图使用`clip-path: inset(0 X% 0 0)`裁剪（X随鼠标变化）
3. 鼠标移动时更新裁剪百分比和竖线位置
4. 绘制竖线分隔符 + 圆形拖动手柄

**DOM结构：**
```html
<div class="mw-compare-container">
  <img class="mw-new-image" src="新图URL">
  <img class="mw-old-image" src="原图URL">
  <div class="mw-slider-line"></div>
  <div class="mw-slider-handle"></div>
  <div class="mw-actions">
    <button class="mw-restore">恢复原图</button>
    <button class="mw-reedit">重新编辑</button>
  </div>
</div>
```

**交互逻辑：**
- 默认：显示新图（无滑块）
- 鼠标进入：显示滑块对比模式
- 鼠标移动：竖线跟随，实时对比
- 鼠标离开：恢复显示新图（带延迟）

**样式细节：**
- 竖线：白色2px，带阴影
- 手柄：圆形40px，居中在竖线上
- 过渡：平滑跟随鼠标

### 4. API调用模块

> **已废弃（v1.1.0 起）**：本节描述的自建 `/generate`（MCP 封装）契约已移除，
> 改为直连 ComfyUI 原生 API（`/upload/image` → `/prompt` → `/history` → `/view`）。
> 现行方案见 [2026-10-01-comfyui-direct-api.md](2026-10-01-comfyui-direct-api.md)。

**API规格：**
- 端点：`POST /generate`
- 格式：`multipart/form-data`
- 参数：
  - `ImageInput`: 图片二进制
  - `prompt`: 提示词字符串
- 响应：`application/octet-stream`（图片二进制）

**请求流程：**
```
图片URL → fetch → blob → FormData → POST → Blob URL
```

**错误处理：**
- 网络错误：提示"网络请求失败"
- 服务端错误：显示返回的error信息
- 超时：30秒，提示"请求超时"

### 5. 配置管理

**油猴菜单项：**
- ⚙️ 打开设置面板
- 开启/关闭脚本

**设置面板内容：**
- API端点地址（必填）
- API Key（可选）
- 预置提示词管理：
  - 显示当前预置词列表
  - 添加/编辑/删除自定义提示词

**默认预置提示词：**
- 人物动作编辑
- 人物穿着编辑  
- 背景替换

**存储方式：** `GM_getValue/GM_setValue`

## 技术选型

- 纯JavaScript，无外部依赖
- CSS内联注入
- 油猴API：`GM_addStyle`, `GM_getValue`, `GM_setValue`, `GM_registerMenuCommand`, `GM_xmlhttpRequest`

## 错误处理与边界情况

1. 图片跨域：使用`GM_xmlhttpRequest`绕过
2. 小图片过滤：宽高<100px不处理
3. 动态加载图片：MutationObserver持续监听
4. 重复请求：编辑中禁用按钮
5. API不可用：配置检查 + 错误提示
